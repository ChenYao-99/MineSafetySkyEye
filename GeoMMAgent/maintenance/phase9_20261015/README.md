276条是公开志愿地图中的采场定位线索，查询范围覆盖台湾全岛，**不表示涵盖全部真实矿山或认证开采边界**。年度目录也不能证明未编目的区域安全。优先发现采用相交比例至少50%、时相有序且不属于旧开发矿区/观察窗口；相交不自动放行标签。

原先2023/2025没有新优先对象后，在任何模型预测前另存 `source_extension_protocol.json`，追加2020—2022三个年度。没有改低优先规则，也没有改写原协议。2020/2022旧WKT投影参数与TM2一致，但基准命名不能被自动可靠识别，保留待澄清标记，仅用于粗范围发现和来源查看。

## 用途决定及尚未闭合的条件

- 大裕：灾前已有裸露地表，10米影像不足以独立区分新增破坏和作业变化；只保留来源候选。
- 国华2022：灾后新增裸露区域与官方对象位置基本对应，是更值得继续核查的不同事件线索；仍需正式矿名/作业面对应、旧CRS基准澄清，以及原始高分参考影像或同等独立验证。当前不放行监督。
- 两处原对象很小，退缩10米后仅8和5像素，20米后均无核心。不能凭此宣布完整事故边界或稳定跨矿表现已闭合，也不值得重复围绕这些核心开展微调。
- 和平矿区官方文章可支持“正常采矿可造成SAR异常”的现象依据，仍缺原始光学图准确时相与像素定位；公开作者脚本连接超时，未获取或执行。因此新增可信正常作业负例仍为0，不计算误报率。
- 新增已放行矿山事故标签0、完整事故边界0、正式独立盲测0。两组保持未预测候选状态，不能描述为已经通过的独立测试集。

接下来优先核实国华2022的矿权对应、源坐标基准和高分图资获取条件，同时寻找面积更大、原始影像与多边形成套且正常作业有独立依据的公开案例。数据资格不足时继续换来源，不重复扫这几个核心像素的学习率或阈值。取得足够可信支持后再冻结事件/矿区用途，比较默认与离线候选，然后展开矿山多尺度对照。
