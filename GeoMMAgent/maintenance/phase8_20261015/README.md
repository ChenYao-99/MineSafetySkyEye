先执行4次固定实验：源样本回放对照／回放加部分监督，各两个随机种子、每次80步。新监督相对回放对照有所改善，但两者都弱于原默认模型，暴露了微调遗忘及新样本裁块与部署窗口不一致的问题。这4个权重未保留，结果没有重写。

随后固定4次针对性实验：冻结教师对照／教师保持加部分监督，各两个种子、每次200步。保持编码器及全部BN统计不变，训练窗口与生产推理窗口逐元素一致。

教师输出用于保持已有模型函数，不是人工标签或安全负例。未知区域不参与正负真值监督，但参与输出一致性约束；已知正例核心从该未知区域约束中排除。
