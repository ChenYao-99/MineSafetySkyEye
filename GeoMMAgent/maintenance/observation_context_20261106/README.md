# 2026-11-06 无效观测上下文与接续验收

上轮11月4日修复和清理均已落盘并通过验证，额度中断只影响总状态索引。本轮继续修正缺失观测导致的推理不一致，没有训练CNN或更换权重、阈值。

## 实际问题与行为

两期影像的各自有效区不同，即使共同可见区完全相同，原实现仍把不同的非共同区域送入图块归一化和CNN，可能产生边缘假变化。现在两期只从同一共同有效区生成推理上下文；缺失处使用最近有效像素的整组波段，单期按自身有效区处理。有效像素保持原值，光谱统计仍使用原始观测。填充像素始终被排除，不成为新观测或地质证据。

充分观测输入直接沿用原数组，不改变数值。参考尺度模式先保留原有有效观测单元筛选，再为模型准备上下文。质量不足、无有效区域、保留集隔离等前置拒绝路径不因填充而放行。接口的`input_quality`附带上下文方法和仅作上下文的像素数；实现标识更新为`streaming_windows_v3_observed_context`。

## 证据及限制

`context_protocol.json`在试验前固定四个既有开发矿区及两种遮挡，不使用标签选择位置。8项固定测试中，最近有效像素方式相对零填充的平均概率偏差比为0.1956、掩膜翻转率比为0.1528（约下降80.4%和84.7%），7/8项两指标同时不劣。LasCruces矩形遮挡的翻转率由0.0724%升至0.1759%，约增加0.10个百分点，未隐藏此项退步。

这些是模拟缺失相对原输入预测的稳定性，不是实地精度、跨矿F1或新的独立盲测。不能推断所有云遮挡、材料或模型都获同等改善。

`development_acceptance.json`重放全部8项指标，并使用真实GPU确认LasCruces单期、ROI和双期统计与11月4日充分观测结果一致。相同真实DN、不同合成缺失边界的两期检查得到零新增/扩大/消退和零净变化；合成质量掩码只用于软件验收，不是实际天气资料。6项新增回归还确认共同观测内真实变化不会被抹掉。
