## 本轮改动

- 角色输入补齐ROI是否已圈定及像素框、统一客观事实字段、定标与实测波段声明；把已知输入与待核查的现场条件区分开。
- 证据核查JSON除案例/请求/引用格式外，也检查量测数值、单位及对已提供条件的否认。错误核查意见不会继续传入写作角色。
- 双期提示、工具文字和事实降级统一按两位小数显示百分比与净变化百分点。相对变化率不再混入这段提示；T1为零时相对变化率保持不可计算，不用微小分母生成巨大数值。
- 前端使用中文角色名称，去掉空核查段落，显示阻断原因和未采用的原始记录；双期待复核事项标记T1/T2。
