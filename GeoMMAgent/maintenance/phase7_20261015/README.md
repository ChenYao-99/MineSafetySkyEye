## 新增的有效参考

`references/TW_ZHONGHE2024_PARTIAL/qualification.json`保存当前用途决定。

中和矿场取得1个B级独立公开崩塌对象参考，原始编目行号1486（从0计），原图面积约4,751平方米。原始标签明确使用2月14日和4月29日两期Sentinel-2；县政府公开救援记录第2–3页记载了中和矿场崩塌、道路破坏及救援。历史OSM提供采场定位线索，原始两期像素已与原始矢量叠加检查。

这个对象在10米网格上为47个参考像素，退缩10米后只有5个共同可观测核心像素，退缩20米、30米后为0。因此优先用于对象级检出参考；不能据此宣称完整事故边界、可靠全像素分割或足够的矿山训练量。10米退缩是一项敏感性选择，并非经测量证实的定位误差。

另整理5个周边公开崩塌对象作为辅助地表失稳参考。退缩20米后共95个共同可观测正例核心像素；它们不是新增的5个矿山事故或独立矿区。两份掩码统一采用1=参考正例、255=未知、0=负例（本轮没有提供负例）。

当前`training_allowed=false`、`final_blind_test_allowed=false`。完整矿山事故范围、岩崩/落石/滑动的精确子类型、绝对地面误差仍未认证。LMHLD作者版本说明台湾来源为2018，而本例为2024；尚未证明所有源训练图块与本矿的地理无重叠，也没有将此例宣称为已完成的独立盲测。

## 保留的争议与作业证据

- 新城山：官方崩塌几何与震前采场线索有相交，但矿方2024报告第61页对开采区的描述与周边边坡崩落需要区分。保留为范围争议复核案例，没有选择有利的一方将其变成正例或安全负例。
- 和平：[官方技术文章](https://tech.ardswc.gov.tw/EPaper/Home/EPaper?PaperID=78b8b3e4-5c52-4f96-a2b0-735981390952)明确把所展示的SAR异常解释为采矿作业造成的误报。这是有价值的背景混淆证据；原图缺少可直接匹配的光学取像日期和坐标，当前没有转成原生像素负标签，也没有把同名区域内其他矿场一并当作负例。
- GSMMA旧报告链接返回HTTP 200，但正文实际是HTML 404页。已按文件签名拒绝并清理错误文件，保留失败收据，没有当成成功获取的事故调查PDF。

1. 从其他年份/事件的官方原始GIS编目与已定位矿场交叉筛选，补不同事件组；不把同次地震的多个对象重复计算为独立事件。

4. 固定矿区/事件划分、用途、预训练地理接触说明及辐射偏移协议，再开放训练或最终验收。
5. 新监督达到可开展实验的条件后，比较矿山单尺度、多尺度、相近计算预算的单尺度集成。当前不重复旧矿参数扫描。
