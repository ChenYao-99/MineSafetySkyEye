# 能登原始来源与真实采场核查：本批已验收

日期：2026-10-15。状态入口：state.json（本地实验产物 `state.json`）。数据统一位于 `D:\LMHLD\datasets\noto_reference_screen_20261015`。本批未训练、未运行检测模型、未调用外部生成接口，未更换默认权重；两个模型和两个保护登记的SHA256保持不变。7项来源用途检查通过。

## 实际新增了什么

- 取得日本国土地理院完整发布的能登地震DEM判读GPKG，保留68,844个原始组成多边形及原有分类、坐标和来源。另取得5个分区的2,345个原始航片判读对象、调查覆盖和云区几何。它们主要是自然山坡，组成对象不等于事故数，更不等于矿区数。3个无效光学几何未擅自修复或使用。
- 通过地质原资料、公开地图定位和原始航片核对，找到**1处可清楚辨认的阶梯采场**。公开简化矿业图层没有标出此处；地质报告支持仁行一带存在采石活动，仍未取得该场的正式许可名称或法律范围。项目内部ID `JP_NOTO_NIIGYO_QUARRY_SOURCE_CANDIDATE` 用于关联来源，不是已认证矿名。
- 为同一采场保留2020年度航片、**2023-12-06原生10米Sentinel-2震前RGB及原生20米SCL**、2024-01-05和01-11航片、2024-04-05至04-26航片。卫星小窗口SCL仅有4/5/6类；这表示本景类别质量筛查通过，不代表地面安全。航片为发布后的正射瓦片，不能称为未重采样传感器原始影像。2020年度范围为2020-04-01至2021-03-31，未认定具体拍摄日。
- 搜索窗内4个原始航片判读对象已逐一关联DEM判读。保存了完整源文件、原始对象索引/fid、原始时相、几何对应、内部面积和同位置多期核对图。搜索窗仅用于找对象，**没有将方框冒充矿界或事故边界**。

1月11日有大面积积雪；1月5日也有雪、薄雾和保留植被的滑体。4月裸露面更清晰，但不能把4月像素外观当成1月事故标签。2023年12月震前影像支持近期地表对比，10米分辨率不能认证1米边界，12月6日至震前仍存在观测空档。

此前冻结的大对象优先条件为源面积至少10,000平方米、20米内缩面积至少2,500平方米，本批没有对象同时满足。它是大尺度来源的优先条件，不是小滑坡不存在的判断；后续应单独核查细尺度任务，不能为了扩大条数放宽门槛后继续在几个像素上反复拟合。

## 排除、保护与清理

- 54个公开矢量瓦片共642,947字节，解码得到6组采石用地，其中2组与原冻结检索范围相交，其余属于瓦片边缘；不能说找到6座能登矿。未取得与此次灾害相交的新增大对象，不代表实际不存在矿山事故。
- 历史论文的5个采场坐标用于定位，基准未说明；已对照原页纠正OCR。2019报告中的地名查询点只是町级线索，旧通用代码附带的东京基准假设与该查询无关，已明确忽略，原登记保留。柏原误定位清理地与西方寺历史点均未确认当前采场。
- 公开ZIP主机存在旧TLS协商问题；没有降低证书安全验证。改从官方地图定义读取原始GeoJSON。Overpass多节点未成功，改用受预算约束的公开矢量来源，未无限重试。
- 6个海啸覆盖/云区文件未混入滑坡调查覆盖，已删除正文、保留来源收据。正常台阶、未标注地区、震前裸地都没有转成安全负例。
- 所有日期属于同一矿区/事件组，未拆进训练集和盲测集。当前批次未查看模型输出；本地LMHLD区域目录及登记未发现能登，但完整历史预训练暴露仍未核清，因此尚不能声明完全未见的独立盲测。
- 移除约**78.78 MiB逻辑文件量**的全黑、云遮、位置偏移、未确认采场试探影像及不必要渲染页，保留约127.95 MiB数据（不含最后少量清单增量）。部分原始瓦片使用硬链接，前者不代表磁盘净释放量。清理只作用于本批D盘目录；失败/淘汰试探收据合并保留，工具阻止静默重下载。
