## 已落地的改动

- 事实字段更正时不再继续交付旧解释；原始草稿单独保留。两处已记录的错误数字已通过本地重放验证。
- 证据记录绑定案例和事件；替代关系必须明确且哈希对应。不同案例不能互相替代，混用案例来源的单份结构化报告被拦截，旧记录仍保留在历史中。
- 开放式ReasoningAgent实际接收前序角色输出、当前任务与证据范围，并使用开放式报告提示。选择题路径保持单独处理。
- 检查CAMEL和流式响应的结束原因；长度截断、内容过滤或空输出中止下游角色。自由问答返回明确不完整状态，检测报告使用带来源的事实降级。
- 默认语言模型迁移到实际接口可用的 `qwen3-vl-plus`，统一非思考模式、有限输出与上下文预算，关闭SDK隐藏重试。健康检查也使用当前配置模型。
- 单期覆盖比例采用与显示精度一致的核对；双期T1/T2占比、净变化百分点和变化区域数一并检查，减少仅检查部分字段造成的漏检。
