## 本轮修复

- 上传检测、报告和导出传递同一ROI、波段声明、模型、实例阈值与NIR开关。ROI内统计、几何、分级与提示词一致，标注图圈出范围。
- RGB复制红波段仅用于检测器输入；NDVI/NDWI标为不可用。RGBA透明度不再误用作NIR；真实四波段需声明BGRN/RGBN。
- 两期变化默认自动配准并检查匹配、残差和共同覆盖；失败时不给变化判断。已配准模式要求同尺寸、同范围、同分辨率并明确为用户声明；两期使用所选模型。
- 模型缺失/未知、非法ROI/GSD等返回明确状态，不静默改用基座。大图分批推理默认256窗口；限制输入体积。
- 智能体和调度器按请求创建独立记忆；超时任务仍占用有上限的执行槽，防止无界积累。提供者超时可由`MODEL_TIMEOUT`控制。
- 模型不可用时只输出检测事实汇总，并标记`generation.status=fallback`和降级状态。没有生成模拟风险判断。
- 几何校验绑定实例、指标和单位；检测面积/数量与引用编号也校验。修复请求携带原始事实，仍失败则展示事实汇总。
- 报告缓存30分钟、最多8份。导出以`report_id`引用屏幕上的同一份结果；服务重启或过期后明确要求重新生成。
- 中文报告手动按显示宽度换行，避免PNG导出时文字拉宽或溢出。
- 知识库11条扩至46条、15个来源；法规、标准元数据、技术资料与项目说明分开。前端显示来源、适用范围和核对日期。

## 配置与交付

两个仓库须一起交付，包含知识JSON文件、各自requirements、模型文件和示例数据。检测权重未修改。本次是程序与知识内容修复，不是新一轮模型精度实验。

可配置项：

| 环境变量 | 用途/默认 |
|---|---|
| KAT_LMHLD_DIR | 检测侧目录，默认D:/LMHLD |
| KAT_DETECTOR_PY | 检测环境Python路径 |
| KAT_DATA_ROOT | LMHLD测试数据目录，沿用原F盘默认路径 |
| KAT_MODELS_ROOT | 默认检测侧目录下models_prior |
| KAT_MAX_BATCH | 上传/对比推理窗口批量，默认256 |
| KAT_MAX_UPLOAD_BYTES | 解码文件大小，默认32MiB |
| KAT_MAX_IMAGE_PIXELS | 图幅像素数，默认16,777,216 |
| MODEL_TIMEOUT | 大模型提供者请求超时，默认60秒；已有设置优先 |

现役mine权重为`real_ft_T1b_ours_seed42/best_model.pth`，阈值0.40。服务返回实际模型和阈值。参赛指标须与同一模型、输入协议、范围与后处理口径对应。
