# 知识库校准与扩充记录

本页记录 2026-10-01 的校准。当时有 46 个知识片段和 15 个来源，其中 14 个为外部来源，1 个为项目能力说明。当前条目和来源以 [knowledge_chunks.json](knowledge_chunks.json) 和 [knowledge_sources.json](knowledge_sources.json) 为准。

`knowledge_sources.json`存出处、发布者、发布日期、核对日期、适用对象与核验深度；`knowledge_chunks.json`存编号、分类、定位、摘要与关键词。`knowledge_base.py`启动时验证并合并，保留原11个条目编号。

## 校准内容

- REG-002改为GB/T 37573-2019《露天煤矿边坡稳定性年度评价技术规范》。另增加GB/T 37697-2019变形监测标准，两条仅引用已核对的元数据，不假称已经阅读标准全文。
- REG-003改为矿安〔2024〕41号真实的露天矿山补充情形：人员集聚区受到灾害威胁、极端天气停工撤人。原来的形变速率描述无对应依据，已删除。
- 补入2026年施行的煤矿安全规程（第17号）与煤矿重大事故隐患判定标准（第21号），并说明旧125号文件废止关系。REG-017/018对应第21号标准附件第15条选定条款。
- 区分119号文件的150米建设范围与88号文件的200米重大隐患情形，区分煤矿和金属非金属矿山。
- 去掉统一35°高风险阈值、卫星/无人机必然识别毫米裂缝、成本必降至十分之一、多源证据未齐就不响应等无可靠依据的旧表述。
- 增加影像波段、NDVI、透明度、合成NIR、云雪与采集时间、ROI、米制换算、配准、指标口径、验证边界与报告引用条目。

## 来源与核验深度

| 来源 | 核验范围 |
|---|---|
| 国家矿山安全监察局119号、88号通知 | 公开正文中的相关章节 |
| 41号补充情形 | 湖南省政府转载的国家局正文 |
| 2025年智能化建设指南 | 国家局发布会解读；不当作指南逐条原文 |
| 第17号煤矿安全规程 | 公布文件、版本及施行日期 |
| 第21号重大事故隐患标准 | 公布文件及附件第15条选定条款 |
| 37573、37697国家标准 | 官方元数据；未获取全文 |
| USGS、ESA | 一般技术资料和官方任务说明；不是中国矿山法规 |
| 新井煤业事故 | 应急管理部公开调查报告的相关内容；历史案例 |
| 项目能力说明 | 当前实现与使用边界；不能作为法定阈值依据 |

完整原文链接见来源登记表。新增条目需先有可核查来源和原文定位，再写摘要。不能将模型生成的建议标成法规原文，也不能把现场试用、标注或检测真值写成未发生的成果。

## 使用与检索验证

查询会返回出处与适用范围；注入大模型的资料带`[REG-002]`等编号。知识回答引用的编号必须来自本次检索，缺失或编造引用时回退到原始资料展示。标准编号检索会优先匹配标题中的同一编号。

```powershell
python tests/test_knowledge_catalog.py
```

此测试覆盖原编号兼容、来源完整性、标准名称、200米在线监测、RGB/NDVI、配准、72小时位移、2026年煤矿标准及无匹配查询。它不等于矿方专家审核，也不保证大模型不会产生新的语义错误。
