## 〇、先决问题：第十三组的误报率有 45% 评估泄漏（复核查出）

## 一、实验设计

**三路互斥的 NIR 注入**（`DS.__getitem__`；NIR 通道只有一个位置，必须互斥）：

```
r = rng.random()
if   r < nir_synth                     →  合成 NIR（有信息、带噪的估计）
elif r < nir_synth + nir_dropout       →  NIR := R（零信息）
else                                   →  真 NIR
```

| 臂 | nir_synth | nir_dropout | 真NIR/合成/R |
|---|---|---|---|
| **A 对照** | 0.00 | 0.50 | 50 / 0 / 50（＝第十三组 realfit 配方） |
| **B** | 0.25 | 0.50 | 50 / 25 / 25 |
| **C** | 0.50 | 0.50 | 50 / 50 / 0 |

**每臂 4 个 seed（42–45）**。首轮 2 seed 时发现判据②③的边缘差异与臂内极差同量级，故补种子。

**协议天然对齐**：`x` 进 `DS` 前已由 `norm_patch` 归一化到 [0,255]，正是合成器的训练域。
合成 NIR **预计算**（逐样本前向会让训练时长翻倍），几何增强时对 `x/y/xs` 同步翻转旋转。

**评估矩阵 = 训练臂 × 推理期 NIR 来源**。部署时推理用哪种 NIR 是可选的（`nir_synth`
开关），所以必须看全矩阵。

**模型选择**：按 **val_loss 最低**选优。val split 完全在留出集之外，不污染留出集。

**预先注册的成败判据**（开跑前写死，三条须同时满足）：
1. 留出图块误报（合成 NIR 推理）**不高于**对照臂 A
2. 白格分离度（合成 NIR 推理）**高于** A
3. 源域 F1（真 NIR）保留 **≥ 85%**（基线 0.7372 → ≥ 0.6266）

## 四、Post-hoc 诊断

### 4.1 判据 ②（分离度）奖励了"整体更爱报警"的模型

看原始响应值（合成 NIR 推理，白格）：

| 臂 | 滑坡区 ls_S | 背景区 bg_S | 分离度 = ls−bg | 同期留出误报 |
|---|---|---|---|---|
| A | **0.52 ~ 0.56** | **0.29 ~ 0.32** | 0.219 ~ 0.250 | **24.5%** |
| B | 0.43 ~ 0.52 | 0.22 ~ 0.29 | 0.209 ~ 0.236 | **13.9%** |

**对照臂 A 的滑坡区与背景区响应同时更高** —— 它的"高分离度"来自整体响应水平被抬高，
而非更好的判别力；它在同一个留出集上到处报警（24.5%）。用绝对差值做判据会**系统性
偏袒过度激活的模型**。

去混淆后（相对分离度 `(ls−bg)/mean(ls,bg)`）排序反转：**B 0.6159 > A 0.5693 > C 0.5671**。

### 4.2 判据 ③ 测的"真 NIR 条件"在部署中不出现

upload 系列模型服务的是**上传的真实影像**，而真实影像**没有近红外波段** —— 部署时的
NIR 只可能是 `NIR:=R` 或合成 NIR，**永远不会是真 NIR**。故该指标是源域健康度，不是部署指标。

在**两个真实出现的条件**下：C 的 F1(NIR:=R) 为 **0.5203（比 A 高 4.6pp）**，B 高 2.0pp。

### 4.3 部署相关的取舍前沿（混合系数 α 扫描）

推理期用 `nir = α·synth + (1−α)·R`，扫 α ∈ {0, 0.25, 0.5, 0.75, 1}（4 seed 平均）：

| 臂 | α=0 | α=0.25 | α=0.5 | α=0.75 | α=1.0 |
|---|---|---|---|---|---|
| **A** 误报 / 分离度 | 8.07% / 0.2188 | 11.60% / 0.2270 | 15.70% / 0.2336 | 20.16% / 0.2383 | **24.52% / 0.2399** |
| **B** | 7.61% / 0.2069 | 9.09% / 0.2137 | 10.35% / 0.2177 | 11.89% / 0.2204 | **13.87% / 0.2218** |
| **C** | 8.74% / 0.2041 | 9.20% / 0.2103 | 9.78% / 0.2148 | 10.55% / 0.2185 | **11.85% / 0.2210** |

**注入把合成 NIR 的"误报价码"从 A 的 +16.5pp 降到 C 的 +3.1pp**（从 α=0 走到 α=1）。
但**没有任何 α 配置同时超过现役基线（A + α=0：8.07% / 0.2188）**。

### 4.4 ⚠ 决定性对照：分离度轴上臂间比较**不具判别力**

复现对照暴露了一个此前未被识别的方法学问题。`--dump-split` 落盘的是**排序后**索引，
而原训练按 `rng.choice` 的**置换序**追加样本 —— 集合完全相同，仅顺序不同。
补跑一次置换序（`--use-perm`，同配方同 seed）：

| 配置 | 样本顺序 | 白格相对分离度（合成NIR） | 留出误报（合成NIR） |
|---|---|---|---|
| v1（原始 realfit） | 置换 | 0.6527 | 25.26% |
| **A_perm_s42** | **置换** | **0.6719**（末轮） | **20.26%** |
| A_s42 | 排序 | 0.5379 | 23.16% |
| A 四 seed 均值 | 排序 | 0.5693（0.538~0.607） | 24.52% |

**单是样本顺序一项，就让相对分离度移动了 0.10；而臂间差异只有 0.047**
（A 0.5693 vs B 0.6159）。**结论：分离度轴上的臂间差异被顺序效应淹没，不可据此断言优劣。**

反过来，误报轴上的顺序效应仅约 **4.3pp**（25.26% → 20.26%），
**远小于臂间差异 11~13pp** —— **误报轴上的结论是稳健的**。

> **可复用的方法论教训**：在这种量级上做 A/B 实验，必须**先做"同一配置换实现细节"的
> 对照**，确认该指标的可重复性下限，再判断臂间差异是否超出它。否则会在噪声里读出"结论"。

## 五、其他子系统的观测

### 5.1 未见矿山场景（抚顺西露天矿）—— **B 臂在两种口径下都最低**

整幅风险占比（2304×2304，走完整 API 链路）：

| 通道 | NIR:=R | 合成 NIR |
|---|---|---|
| base | 29.96% | 25.66% |
| **realfit（现役）** | 1.34% | 2.09% |
| ctrl（第十三组对照） | 1.68% | 2.45% |
| A_s42 | 1.27% | 2.33% |
| **B_s42** | **0.67%** | **1.14%** |
| C_s42 | 1.96% | 2.37% |

**B 臂把现役的抚顺风险面积再砍一半**（1.34% → 0.67%）。

> ⚠ **但必须同时看这个**：B 臂在**白格滑坡区的响应也是全部模型里最低的**
> （0.3828 vs 现役 0.4847；背景 0.2382 vs 0.2968）。**B 是"全局更保守"，
> 不是"判别力更强"** —— 它的低误报与低真响应是同一件事的两面。
> 抚顺矿坑的响应同样从 base 的 0.3175 降到 0.0562，而第十三组已记录
> **矿坑响应下降的双面性无法判定**（可能是误报被抑制，也可能是真实边坡风险被压制）。

### 5.2 先验融合子系统在真实影像上被合成 NIR **救活**（正面结果）

`compute_prior_map` 的裸地项来自 NDVI = (NIR−R)/(NIR+R)；**NIR:=R 时它恒为 0**，
块内 min-max 后退化为常数 1.0 —— 先验图有一半是死的。本组首次量化了它的**块内判别力**
（`mean(prior|GT=1) − mean(prior|GT=0)`，仅用同时含正负的块）：

| LMHLD 区域（32px 瓦片） | 真 NIR | **NIR:=R** | **合成 NIR** |
|---|---|---|---|
| 意大利 | 0.1796 | 0.1540 | **0.2331** |
| 尼泊尔 | 0.1317 | 0.1096 | **0.1950** |
| 日本 | 0.1643 | 0.1275 | **0.2037** |
| 九寨沟 | 0.0917 | **0.0437** | **0.1375** |
| 汶川 | 0.0827 | **0.0382** | **0.1219** |
| 台湾 | 0.1343 | 0.1178 | **0.1850** |

**真实影像（白格，ROI 弱标注，块级）**：

| NIR 来源 | 先验判别力 gap |
|---|---|
| `orig` / `NIR:=R`（二者在真实影像上恒等） | **−0.0073（负值，等于没有）** |
| **合成 NIR** | **+0.0403** |

**两个结论**：
1. **先验融合在真实影像上确实是"半死"的** —— NIR:=R 下判别力为负，这条路走不通；
2. **合成 NIR 不仅恢复它，还超过真 NIR**（如汶川 0.1219 vs 0.0827）。
   机制推测：合成 NIR 是从 RGB 学出的光滑估计，其 NDVI 因此更贴合**可见光下的滑坡外观**，
   而真 NIR 反映的是另一种物理量。此解释未经检验，仅记录现象。

> ⚠ **边界**：先验图**不在**部署的 `detector.py` 消费路径上（它作用于训练期的先验加权
> 损失与 D-S 融合评估）。故这是"**一条能力被打开**"，**不是**已测得的端到端增益。

### 5.3 按指标选优的净影响（原为"每 5 轮覆盖存、实存末轮"）

12 次训练中**末轮即最优的只有 3 次**。按 val_loss 选优的平均变化：
**误报 −0.52pp、分离度 +0.0001**。收益小但**几乎免费**（val_loss 每轮本就计算），已合入。

> 注：选优并非总是更好（如 B_s42 的末轮 F1(真NIR) 0.6449 优于最优轮 0.6114），
> 故**两个权重都存**（`best_model.pth` / `last_model.pth`），报告里都列。

### 5.4 增强非等变性（预计算的代价）

合成 NIR 是预计算的，几何增强时同步翻转旋转。因合成器非等变，
`synth(flip(rgb)) ≠ flip(synth(rgb))`：**实测 `mean|synth(flip)−flip(synth)| = 8.563`**
（0–255 域，约 3.4% 量程；三种子实测 8.144~8.563，见 `experiments/nir_train/run_p16.log`）。

这是一次**有界的标签噪声**，且三个臂中 B/C 用同一近似、A 完全不用，**不影响臂间公平性**。

## 六、结论

1. **训练期注入是有效的"解药"** —— 它确证了第十五组的病因诊断：合成 NIR 的误报爆炸
   **确实源于模型没见过它**。注入后误报 **24.52% → 11.85~13.87%**（区间不重叠，
   远超顺序效应 4.3pp）。这是本组最稳健的结果。
2. **但解药没有产生净增益** —— 解完之后，合成 NIR 在**任何** α 下都不曾在误报–分离度
   权衡上稳定胜过"不用合成 NIR"。**合成 NIR 这条路线的价值上限因此被本组界定。**
3. **分离度轴上的臂间比较不可靠** —— 顺序效应（0.10）大于臂间差异（0.047）。
   本组所有基于分离度的排序都应视为**不具判别力**。
4. **一个正面副产物**：合成 NIR 让**先验融合子系统在真实影像上从"死"变"活"**
   （−0.0073 → +0.0403）。这条路值得单列一轮做端到端验证。

| 已发布数字 | 按第〇节修正 |

## 七、诚实边界

1. **判据未通过就是未通过**。第四节是 post-hoc 分析，用于理解**为什么**，不能反过来当作通过。
   若要重新检验"相对分离度"这一判据，应重新注册再做。
2. **分离度的臂间比较已被第 4.4 节证伪**（顺序效应大于效应量），全文凡涉及分离度排序处
   均已降级为观察，不作结论。
3. **白格是唯一有真实滑坡标签的场景**；留出负样本来自 5 个场景（城区/农田/港口/林地/裸地），
   **未覆盖排土场、尾矿库、采场台阶**等矿山特有地物（第十三组已记录此缺口）。
4. **抚顺矿坑响应下降的双面性无法判定**（第十三组已记录）：可能是误报被抑制，
   也可能是真实边坡风险被压制。**本组未能解决。**
5. **合成 NIR 不是物理反射率**，NDVI 等光谱指数仍不可用它计算（第十五组已记录）；
   5.2 节测的是**先验图**（块内相对量），不是辐射量。
6. **臂 A 与 v1 不是逐位复现**：顺序不同（见 4.4）。A 四 seed 与 v1 的源域 F1 接近
   （0.6411 vs 0.6568）但白格指标差异明显，已用 `--use-perm` 对照定位为顺序效应。
7. **未做**：合成 NIR 与先验加权的**联合训练**（5.2 指出的那条路）；
   合成器的多架构/多尺度对比；NDVI 的辐射定标重建；矿区场景的合成 NIR 专项验证。
