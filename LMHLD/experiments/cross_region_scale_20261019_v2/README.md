## 本轮结果

主对照为“尺度增强训练＋五视图多尺度推理”相对“固定尺度训练＋五视图单尺度变换集成”。同架构、同训练样本/步数、同推理次数。下表先按六地区宏平均，再平均两个种子；不是与旧部署模型混比。

| 指标 | 同预算基线 | 固定多尺度组合 | 变化（百分点） |
| --- | ---: | ---: | ---: |
| 小目标半覆盖命中率 | 53.13% | 52.64% | -0.48 |
| 小目标IoU≥0.5一对一匹配率 | 30.24% | 34.50% | +4.26 |
| 整体像素F1 | 56.89% | 55.26% | -1.64 |
| 标注背景误检率 | 3.48% | 3.30% | -0.19 |

只有北海道、九寨沟在两个种子中都提高了半覆盖命中率；北海道同时损失整体像素F1。尼泊尔整体F1在两个种子均提高，但误检变化不稳定。汶川、台湾未出现综合提升。小目标IoU匹配率的收益不能表述为整体检测能力提升。

预先安排的消融也不支持直接推广：仅加尺度训练增强，平均小目标半覆盖命中率下降约3.25个百分点、像素F1下降约1.36个百分点；仅加多尺度推理，前者下降约1.35个百分点、后者下降约0.72个百分点。多尺度推理能改善较弱的尺度增强分支，不能据此声称超过更强的同预算基线。

`results.json`为完整预定对照，`verification.json`复核24份结果、12对初始化与采样顺序、72项来源校准及逐图指标聚合，全部通过。`comparison.png`展示逐地区、逐种子的主对照变化。默认权重与登记文件哈希未变；零官方test预测、零新增矿区预测、零外发调用。实验目录约10 MiB，未复制原始数据或保存训练权重。

这轮是有限训练预算的机制验证，不能证明尺度适配路线或模型能力已经到顶。后续如继续，应另立来源数据训练的尺度选择假设并重新冻结验证，避免在本轮目标成绩上继续挑比例、阈值和检查点。

## 已核对的设置

- 六地区轮流留出：每一组从随机初始化训练，只使用其他五地，目标地区不进入梯度训练或阈值校准。
- 两个种子、两种训练方式，共24组；每组固定1,200步。只比较本轮相同架构与预算，不直接与部署权重混比。
- 完整图块与局部放大的多尺度方式，对比相同五次推理的单尺度变换集成，另保留单次推理结果。此轮是相对影像尺度的机制验证，不宣称已实现物理分辨率自适应。
- 训练每地区512个原始图块；验证每地区256个，尼泊尔采用全部794个以补足小目标。训练/验证选中影像未发现精确重复；无法据此排除未提供地理位置的邻近图块相关性。
- 小目标按名义分辨率折算为不超过2,500平方米的未触边标签连通对象；同时核对像素F1、背景误检、半覆盖召回和对象IoU。不是仅用“碰到一个像素”作为成功。
- 原始数据只读；官方test文件、保留矿区与外部生成接口均不使用。现役权重、登记及服务不修改，实验与缓存只写D盘。
- 原验证集在历史研发中已暴露。本轮“留出”只指新训练及校准隔离，不能称为全新独立盲测；也不能代表矿山事故识别或现场安全验收。

`protocol.json`冻结方法、门槛和代码指纹，`data_manifest.json`保留精确图块行号及内容哈希，`preflight.json`记录训练前检查，`state.json`记录当前状态。首轮抽样预跑因尼泊尔小目标不足而终止，原记录另存，未混入正式结果，缘由见`sampling_amendment.json`。
