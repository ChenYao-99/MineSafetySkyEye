# 第十五组实验报告 · RGB→NIR 波段重建

**实验日期**：2026-09-23
**脚本**：`train_nir_synth.py`（训练）/ `eval_nir_synth.py`（三重验证）
**起因**：第十三组把主因定位到 **NIR 缺失（−32.7pp）**；第十四组证明 Sentinel-2（10m，有真 NIR）
**分辨率不足以支撑单个滑坡检测**。两条合起来指向同一结论：**必须在保持高分辨率的前提下把 NIR 补回来**。

---

## 一、可行性依据（规划期实测，非推测）

LMHLD 的每个图块都是 4 通道数组，`ch0:3`（RGB）与 `ch3`（NIR）**同块共存**——
零配准误差、零时相错配，比常规多光谱合成数据集强得多。

> ⚠ **口径更正（2026-10-01）**：本节原写"LMHLD 提供 **42 万对**完美配准的 [RGB, NIR]"，
> 该数字**无法与任何实测口径对上**，已按下表现场计数结果改写。

配准对的规模（2026-10-01 从 npy 形状逐一计数）：

| 口径 | 数量 |
|---|---|
| 可选训练池（`LMHLD_tiled`，6 个 32px 区域 · train split） | **406,486** 对 |
| 本次实际使用（按区域配平采样，`--per-region 4000`；Gorkha 仅 2,780，全取） | **22,780** 对 + 3,600 验证 |
| 评测基准 `LMHLD_dataset_different_patch_sizes`（另用，7 区域） | 25,365 图块 |

> 训练集实际构成见 `models_prior/nir_synth_metrics.json` 的 `composition` 字段：
> Emilia 4000 / Gorkha 2780 / Hokkaido 4000 / Jiuzhaigou 4000 / Wenchuan 4000 / Taiwan 4000。

**关键实测**：

| | 全局拟合 | **逐图块归一化后** |
|---|---|---|
| RGB→NIR 的 R² | **0.001** | **0.49 ~ 0.89** |

各传感器的 NIR/R 比值从 **2.0（尼泊尔）到 6.4（日本）** 差 3 倍，故**全局域不可学**；
而检测器用的正是 `patch_norm="minmax"` 逐图块协议 —— **二者恰好一致**。

**归一化域内的量化下界**（实测，val 集）：

| | MSE |
|---|---|
| NIR 方差（零预测） | 3171 |
| **NIR:=R（检测器现状）** | **5067** |
| 全局线性最优 a·R+b | 2708 |

注意 **NIR:=R（5067）比"什么都不预测"（3171）还差** —— 归一化域里 R 与 NIR 相关但**远非恒等**，
这界定了合成器的提升空间。

## 二、合成器训练

| 项 | 设置 |
|---|---|
| 架构 | `Unet-resnet18`，**3ch→1ch**（14.33M 参数） |
| 输入/目标 | 逐图块逐通道 min-max → **[0,1]**（256 倍量纲会让 MSE 梯度病态） |
| 数据 | 6 区域**配平采样**（每区 4000 训练 / 600 验证 = 22,780 / 3,600；Gorkha 训练仅 2,780，全取） |
| 数据卫生 | **排除 Rio de Janeiro**（该区为 5 通道，与本任务不兼容） |
| 训练 | AdamW + CosineAnnealing，30 epochs，**146 秒** |

**训练结果**：val MSE **0.017 vs 基线 0.08 → 降低 77.6%**，训练/验证同步下降（无过拟合）。

> 配平采样是必需的：`LMHLD_tiled` 里**台湾一个区域就占 64% 的瓦片**，不配平会被它主导。

## 三、三重验证（缺一不可）

探查阶段就确认过一个陷阱：**5% 噪声的合成 NIR 在均值/标准差上与真值几乎一致，
但与真实先验图的空间相关性为 0** —— 只看像素统计会得到假阳性。故必须做三重。

### ① + ② 逐像素与**空间相关性**

| 区域 | MSE(合成) | MSE(R基线) | 降低 | **先验图相关(合成)** | (R基线) |
|---|---|---|---|---|---|
| 意大利 | 1281.7 | 10423.1 | **87.7%** | **0.719** | 0.541 |
| 尼泊尔 | 1071.2 | 2705.9 | 60.4% | 0.703 | 0.640 |
| 日本 | 1270.9 | 7306.5 | 82.6% | 0.746 | 0.548 |
| 九寨沟 | 1356.4 | 6893.9 | 80.3% | **0.876** | 0.764 |
| 汶川 | 2039.0 | 5111.9 | 60.1% | 0.808 | 0.714 |
| 台湾 | 1592.9 | 6998.9 | 77.2% | 0.633 | 0.551 |

**✓ 通过**：MSE 降低 60~88%，且**先验图空间相关性（0.63~0.88）一致优于 NIR:=R（0.54~0.76）**
—— 合成 NIR 的空间结构确实更接近真值，不是靠分布相似蒙混过关。

### ③ 端到端检测 F1（唯一有决策意义的判据）

⚠ **协议一致性（第一版脚本在此出错，记录备查）**：合成器在 **min-max 域**训练，
故端到端**必须用同样是 min-max 协议的模型**（upload 系列的 `base`/`realfit`）。
区域模型是 **raw DN 协议**训练的 —— 若喂归一化输入，**连"真 NIR"的 F1 都会算成 0**
（第一版实测：意大利真 NIR F1 = 0.0000，那是协议错配而非真相）。

| 模型×区域 | 真NIR | NIR:=R（基线） | **合成NIR** | Δ |
|---|---|---|---|---|
| base×意大利（本域） | 0.7422 | 0.6518 | **0.7281** | **+0.0763** |
| base×尼泊尔 | 0.5998 | 0.5426 | **0.5960** | +0.0534 |
| realfit×意大利 | 0.6638 | 0.4919 | **0.6445** | **+0.1526** |
| realfit×尼泊尔 | 0.6223 | 0.5014 | **0.6231** | +0.1217 |
| base/realfit × 日本/九寨沟/汶川/台湾 | 0.006~0.123 | — | ≈持平 | ≈0 |
| **平均** | **0.2581** | **0.2217** | **0.2543** | **+0.0326** |

**✓ 通过**。且**在本域恢复了真 NIR 差距的 84%~101%（聚合 90%）**（base×意大利：0.6518→0.7281，真值 0.7422）。

**跨域区域收益≈0** —— 因为那些组合的整体 F1 只有 0.006~0.12，**瓶颈是域偏移本身而非 NIR**。

## 四、真实影像验证（决定性）

走完整部署链路（逐图块 min-max → 归一化后替换第 4 通道）：

| 场景 | 模型 | NIR:=R → **合成NIR** |
|---|---|---|
| **白格（真实滑坡）** | base | 分离度 +0.0794 → **+0.1415**（**+0.062**） |
| **白格（真实滑坡）** | realfit | +0.2428 → **+0.2646**（+0.022） |
| 抚顺（未见矿山场景） | base | 整幅风险占比 29.96% → **25.66%** |
| 抚顺（未见矿山场景） | realfit | 整幅风险占比 1.34% → **2.09%**（略变差） |

**混合结论（如实记录）**：
- **真实滑坡场景明确改善**（base +0.062，realfit +0.022）；
- **矿山场景对已适配模型会略增误报**（realfit 1.34%→2.09%）。

## 五、部署

**做成可选开关，默认关闭** —— 因为"真实滑坡改善 / 矿山场景略升误报"的混合结论
不足以支撑改变既有默认行为。

| 层 | 改动 |
|---|---|
| `detector.py` | `detect_image(..., nir_synth_model=None)`：在**逐图块归一化之后**替换第 4 通道（合成器正是在该域训练的）；失败自动回退 NIR:=R |
| `detector_service.py` | 懒加载合成器；`/api/detect_upload` 接受 `nir_synth` 布尔；响应回传实际生效状态 |
| 实测 | 走完整 API 验证：`nir_synth=False` 响应标记 False、`True` 时 True ✓ |

## 六、诚实边界

1. **合成 NIR 不是真 NIR**。它学到的是**归一化域内的空间结构关系**，不是物理反射率。
   因此 **NDVI 等光谱指数仍不能用它计算**（合成值未经辐射定标）——
   部署中 `geo_tools` 的 NDVI 路径**保持不变**，这个不一致是**已知且有意保留**的。
2. **收益集中在模型本域**。跨域区域（日本/九寨沟/汶川/台湾）收益≈0，
   因为那些组合的瓶颈是域偏移而非 NIR。
3. **矿山场景的误报略升**（realfit 1.34%→2.09%），故默认关闭。
4. **未做**：合成器的多尺度/多架构对比；把合成 NIR 用于训练（而非仅推理）的端到端实验；
   NDVI 的辐射定标重建。
