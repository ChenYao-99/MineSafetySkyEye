本轮已完成；默认权重和服务未修改。机器证据以 `protocol.json`、`results.json`、
`verification.json` 和 `single_view/results.json` 为准。

- 冻结两份七来源 RGB 编码器，比较 32/64 像素上下文与解码特征线性头。
  四矿外层留一、来源矿内层留一；仅来源折选择策略和正常区预算。
  8 个外层折均未通过来源门槛，因此没有新增头被应用到外层目标矿区。
  这轮没有改善已有检测结果，不能写成跨矿性能提升。
- 单视图相对 TTA5 的来源批次前向速度比为 3.58/4.11；不是整幅任务加速比。
  种子 42 通过来源门槛后，LasCruces 已知正核心激活率下降 6.28 个百分点，
  未通过最大 3 个百分点损失门槛；种子 43 在来源门槛即被拒绝。两者均未启用。
- 原实现汇总时遇到 NumPy 布尔序列化问题。`initial_implementation.zip` 保留初始
  协议、脚本及测试；协议中记录修正和已有派生文件指纹。未改变策略、阈值或数值。
  修正后的完整来源策略重算、稀疏预测重放和资产指纹检查均通过，5 项单测通过。
