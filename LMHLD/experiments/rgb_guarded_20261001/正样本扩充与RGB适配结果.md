# 矿山正样本扩充与RGB适配结果

更新日期：2026-10-02。新下载、数据、权重、缓存和结果均在D:/LMHLD；原始F盘数据只读。

## 已完成与实际结论

新增Çöllolar训练矿区和Hpakant留出矿区，共2个独立矿区。Çöllolar提取200个不重叠的保守弱正图块；图块数不等于独立事故数。当前外部矿山案例共4个矿区：1个训练、3个测试/参考，其中2个有图示参考、1个仅事件确认。完整原始GIS真值、独立专家审核和现场试用均仍为0。

完成两轮各6组、每组15轮训练，种子42/43/44；保留第一轮内部验证失败记录。二轮正负平衡、BCE/Dice和RGB/四波段配对监督明显改善既有模型的RGB退化，但单模型背景图块激活率11%～16%，未通过10%启用门槛。新增弱正样本没有在两个矿区稳定提高结果，禁止描述为已证实的普遍收益。

最终可选验证版本使用**85%既有mine + 15%新RGB模型的概率组合**。权重只用内部验证选定；源码中没有从矿山测试真值挑权重或阈值。42号种子RGB源域测试F1 **0.4609→0.5007（+3.98个百分点）**；同池背景图块激活率 **4.03%→4.97%（+0.93个百分点）**。三个种子均通过预设源域/RGB/背景回归门槛。系统新增可选`rgb_guarded`，默认`mine`保持既有版本。

## RGB改进与对照设计

两臂初始化、共同样本、优化器、更新数和种子匹配。每批28个共同样本加4个回放样本；一臂回放源域正样本，另一臂换为Çöllolar弱正图块，回放权重均0.25。二轮共同样本按14正/14背景平衡，真实四波段视图与NIR:=R视图同时监督，使用0.5 BCE+0.5 soft Dice。配方选择比较三种子内部验证分数，服务候选种子固定42。

二轮与一轮还改变了初始化、采样和损失，不能把两轮整体改善归因于某一个组件。RGB复制R只是输入占位，没有恢复物理NIR；NDVI/NDWI仍需真实NIR。组合需两次模型前向，存在计算代价。

组合校准阶段将背景内部图块激活上限设为既有模型+1个百分点、RGB F1至少+0.02。粗网格无合格权重后，仅依据内部数据细化为0.05步长，选定α=0.15。三个组合的既有组件都固定为42号种子，只有RGB组件使用42/43/44训练种子；不是三次独立矿区验证。**Hpakant已经在单模型阶段测过，因此组合阶段不能再称新盲测**。Las Cruces更早已测，始终仅为回归。后续任何调参均不得将这些结果再包装成未见验证。

## 保留的失败与验证

第一轮：均匀采样+BCE、基座初始化、配对监督。六组内部RGB退化，全部不具备启用资格，未拿外部测试挑选该轮模型。

| rgb_joint_minepos | 42 | 0.2786 | False |
| rgb_joint_minepos | 43 | 0.2614 | False |
| rgb_joint_minepos | 44 | 0.2520 | False |
| rgb_joint | 42 | 0.3446 | False |
| rgb_joint | 43 | 0.3303 | False |
| rgb_joint | 44 | 0.3147 | False |

第一轮失败、第二轮单模型背景门槛失败、弱正样本收益不稳定、组合有限改善均保留完整日志。12项数据/协议检查通过，新增真实GPU接口与原上传/报告回归另有测试记录。真实2304×2304 RGB影像、ROI与相同两期影像接口烟测通过；设备cuda，单次首次加载加检测约23.81秒。该时间不是现场性能基准。
