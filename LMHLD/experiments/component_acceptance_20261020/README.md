## 冻结与样本边界

- 主方法固定为开发阶段预先列出的面积筛选对照；其选择来自开发结果。原学习筛选主假设失败的记录保留，未改写为成功。
- 在新增样本评估前冻结面积方法、每个骨干、像素阈值、全局保护阈值、对象面积阈值和验收门槛。辅助对照为TTA5、原多尺度和已冻结置信度筛选，不按验收结果切换主方法。
- 样本来自同一北海道/汶川/九寨沟事件的官方val中未进入当前训练、选模、来源拟合/校准或开发评估的原始索引，分别127/264/291张。哈希去重后与当前全部已选val、train都不重叠；新标签没有参与任何阈值或模型拟合。
- 全部标签文件在注册时仅做字节校验；样本按原图索引与影像哈希选入，未按标签内容挑选。精确索引和影像哈希见`protocol.json`，原图/标签复核与预测重算见`verification.json`。
- 本轮是同地区、同事件的新增样本验收。缺乏地理邻接元数据，不能证明空间独立；更早全项目历史中的曝光也不能独立保证。因此不称新地区、全六地区或矿区现场盲测。
- 这682张现已用于验收，今后不能再称未触碰样本；任何后续调参须另留验收数据。

## 固定验收门槛与工程状态

每种子要求：相对原多尺度，纯背景连通域至少减少20%；覆盖检出损失≤1个百分点、各地区≤3个百分点；严格IoU损失≤1个百分点，F1损失≤0.5个百分点；候选量≤TTA5的1.10倍。另要求相对TTA5保留至少2个百分点的覆盖检出与严格IoU增益。全部通过，门槛未因23.37%/20.09%的结果而改动。

默认模型、登记表、旧实验代码与政策均未改。尚未验证RGB生产输入与真实矿区任务收益，不直接替换现役系统。对象误报代理统计定义延续上轮，不能等同现场报警次数。没有新CNN训练、下载、外部调用或官方test/矿区保留集预测。
