# 冻结模型漏检归因

2026-10-19，已完成12组精确模型重放、787个标签连通对象的双种子归因及全部复核，检测训练进程已退出。**主要瓶颈位于当前基础检测分支的响应层；单纯继续优化融合权重的优先级应降低。** 这不是对模型能力上限或地质原因的证明。默认模型、原门控、阈值、原标签及旧实验分数均不改变。

## 归因结果

787个标签对象各评估两个种子，共1,574条对象—种子记录；740条命中、834条漏检。它们不是1,574个独立滑坡。下面的计数按漏检记录池化，与前两轮按地区宏平均的命中率不同，不能混用。

| 冻结响应路径 | 漏检记录 | 漏检中占比 |
| --- | ---: | ---: |
| 两个分支在固定0.5参考下均未达到半覆盖 | 553 | 66.3% |
| 有固定0.5参考响应，但未过原门控阈值 | 143 | 17.1% |
| 单分支已达半覆盖，门控未保留 | 128 | 15.3% |
| 两分支互补的诊断上限达半覆盖，融合未保留 | 10 | 1.2% |

同一对象在两个种子中都漏检的有382个，其中235个在两个种子中都属于双分支弱响应。按当前分支及冻结阈值，融合相关两类共138条（16.5%）；这是标签辅助的可能空间，不是可实现召回收益。其余696条即使像素级选两分支最大值，也未达到原阈值下的半覆盖。

**不能把普遍漏检简单归结为“目标被缩没了”。** 834条漏检中，824条在局部64像素输入中仍有至少一个多数目标单元，只有10条两视图都没有多数目标单元；832条可计算输入对比度中，仅2条全图重采样后对比度低于原生的一半。但这些只是几何占据和均值对比，不能证明细节、上下文或标签可辨性完全充分。

32像素原图的原生探针与既有全图分支、128像素原图的原生探针与既有局部分支，经8组检查在对象覆盖上完全一致。因此这些地区的“原生探针恢复”不是额外取得新细节的证据。真正增加细节的224像素原图子集中，289条漏检有23条仅在同视野保留细节时恢复，其中原属于双分支弱响应的只有5条；另26条保留细节和模糊均恢复，涉及窗口上下文变化等因素。

整个配对探针找回127条旧漏检，同时漏掉27条旧命中。额外计算和窗口变化下，宏平均背景误检率由原门控3.35%升至3.78%，像素F1由57.72%降至55.63%，因此不作为新检测方案采用。保留细节与同视野模糊的差异证明部分响应依赖细节，不能证明原流程的全部漏检由重采样造成。

代表例图复核后另做了明确标注为探索性的±1原生像素位置敏感性检查：固定预测下，将标签对象同面积平移到8个相邻位置，排除越界及其他GT对象重叠。834条漏检仅13条能因此达到半覆盖，全部原属融合未保留类别。该检查不改标签、不改分数，也不能证明这13条标签有错；小幅位置偏差不能解释本轮大部分弱响应。

## 后续优先级

1. **先检验基础模型是否训练充分。** 目前每组仅用五地区各512个原图块、1,200次更新。固定结构与地区隔离，比较更充分训练，并同时报告来源验证与留出地区表现，区分源任务尚未学好和跨地区迁移问题。
2. **将原生细节保留作为受控训练因素。** 与同视野模糊、相同训练/推理预算对照；重新使用来源数据校准阈值，同时验收误检。当前原生探针不直接上线。
3. 只有基础分支产生有效响应后，再决定是否改门控。无需继续在当前少数目标结果上搜索融合比例或阈值。

这轮只定位数值失效层，还无法区分训练不足、跨地区特征不适配、标签语义与可辨性等更深原因。

## 记录与复现

`results.json`保留冻结归因，`verification.json`复核12组状态/旧指标、1,574条分类、787个种子配对和全部缓存哈希，均通过。`position_sensitivity.json`单列事后探索检查，不混入正式指标。`attribution.png`为汇总图，`examples.png`展示按预定规则选择的5个不同对象。压缩网络概率缓存约355.5 MiB，供后续不重训的响应分析；未保留大权重或复制原图。

以下为本轮冻结设置：

- **数值路径**：区分单支已有半覆盖而门控丢失、两支互补但融合未保留、固定0.5参考下有响应但未过原阈值，以及两支响应均弱。像素最大值只是标签参与解释的上限检查，不是可部署方法。
- **输入细节**：记录原目标投影到64像素模型网格后的占据、象限接缝，以及归一化四通道图像中目标与邻近标注背景的对比保持率。标签亚像素占据不等于图像绝对不可识别。
- **配对检查**：同一原生窗口、相同视野和权重下，比较保留细节与先模糊再恢复尺寸；全图按确定性图块覆盖，重叠概率平均，不按GT居中裁剪。探针增加了计算量，未经独立来源校准，结果仅用于诊断。
- **复现保护**：基础模型状态哈希及每张图的原TTA/门控统计必须与上一轮完全一致，否则停止解释。原始数据只读，官方test、矿区及外部API不使用，默认系统不修改。
- **必要留存**：D盘保留无损压缩的网络网格概率和精确行号，后续响应复查可复用；不复制原始影像、不保留大基础模型。概率缓存约408MB未压缩，上限实际以完成后统计为准。代表例按协议选每类最先出现的种子42漏检，最多六例。

这是历史开发数据的回顾性归因，不是新增独立盲测。响应分类并非互斥的物理原因，图块缺少完整地理身份、名义分辨率和邻近相关性限制仍适用。
