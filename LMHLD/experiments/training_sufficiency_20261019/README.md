# 基础模型训练充分性：三地区受控诊断

2026-10-19已完成：6组拟合、28,800次参数更新、24次来源检查点评估。`state.json`、`results.json`和`verification.json`均已通过；训练日志归入`training.log`。

## 结论

近期的1,200步跨地区从零训练配方仍有优化空间；额外训练加学习率重启产生真实收益。但本轮不能证明已经训练充分，也没有同时闭合稳定小目标检出与低误检。

来源选择半集F1的六组平均从69.06%升至71.72%。固定训练监测损失从0.3607降至0.3054，来源验证损失从0.3725降至0.3469。六组均按来源验证选中4,800步；最后一个区间来源F1平均仍提高0.98个百分点，因此不宣称收敛或能力上限。

**现役默认矿区权重是另一条训练链。** `experiments/nir_train/finetune_T1b_ours.json`记载30轮微调，最佳验证损失在第29轮。本轮1,200步模型不是它的全部训练历史；本轮也没有检验延长其历史微调的效果。

## 留出地区结果

三地区等权、种子等权平均，使用各自来源校准阈值：

| 指标 | 1,200步 | 来源选中权重 | 差值 |
|---|---:|---:|---:|
| 像素F1 | 58.55% | 65.58% | +7.03个百分点 |
| 小滑坡覆盖检出 | 43.24% | 47.98% | +4.74个百分点 |
| 小滑坡IoU≥0.5匹配 | 25.34% | 26.04% | +0.70个百分点 |
| 背景像素误检率 | 2.66% | 3.61% | +0.95个百分点 |

| 留出地区 | F1：短→长 | 小对象覆盖检出：短→长 | 背景FPR：短→长 |
|---|---:|---:|---:|
| 北海道 | 49.80% → 59.62% | 20.66% → 24.13% | 0.69% → 1.18% |
| 汶川 | 52.83% → 64.74% | 21.11% → 31.85% | 1.59% → 3.40% |
| 九寨沟 | 73.01% → 72.38% | 87.94% → 87.94% | 5.70% → 6.24% |

北海道和汶川F1在两个种子均改善；九寨沟在来源校准阈值下两个种子均略降。小对象覆盖检出5/6组提高，严格IoU匹配仅2/6组提高；背景FPR在6/6组均增加。故不能将整体F1提升表述为稳定改善完整小滑坡边界。

固定0.5阈值的辅助口径：F1从63.80%到68.34%，小对象覆盖检出从53.55%到57.06%，背景FPR从5.21%到5.48%。九寨沟首种子在两种阈值口径下F1变化方向不同，说明跨域校准还需要单独验证。

本轮共768张不同留出原图块、622个符合定义的标注小连通域；两个种子复用这些图块，不能把它们算成两倍独立样本。小对象指非原图边界截断、名义面积≤2,500m²的8连通域；覆盖检出要求预测覆盖≥50%真实对象，IoU指标使用一对一匹配。背景FPR是数据集标注背景像素比例，不是现场每班告警率。

## 实验与复核边界

- 预先选择北海道、汶川两个弱响应较多地区及九寨沟对照，每个种子42/43；这些是历史已暴露开发数据，不是新增盲测或全部六地区验收。
- 每组只用其余五地区各512张原图块。六地区原始train文件共有17,275张，本轮并非全量训练；其他实验也不能由此被宣称已用尽LMHLD。
- 同一Unet++/ResNet34随机初始化、4通道BGRN、64×64全图块、逐原图块逐波段0..1归一化、损失与采样配方。前1,200步精确复现旧模型状态和采样哈希。
- 保留AdamW动量，将学习率重启至0.0003，再余弦下降至0.00001，追加3,600步。它检验预算加调度变化，不能把收益完全归因于步数。每组2,560张来源图块，对应约9.375→37.5遍样本量。
- 1,200/2,400/3,600/4,800步仅按来源选择半集F1挑检查点，另一半来源图块校准阈值。选择决定先落盘，之后才推理留出地区。2%约束是来源地区平均背景FPR，不能保证留出地区≤2%。
- 源码冻结，旧结果不改，不复用旧骨干上的尺度门控。根据源代码控制流、分割与哈希检查选择/校准/评估隔离；这是本地可复核流程，不代表外部见证。
- 复核6份权重状态及文件哈希、24个来源检查点、来源选择与校准半集互斥、原标签哈希；从FP32缓存重算三种方法全部留出指标及选中权重的来源阈值。7项新增测试和9项已有指标/排除规则测试通过。
- 原始数据只读。默认模型、登记表、矿区保留集与旧结果哈希未变；官方test预测0、矿区新增预测0、外部API调用0。
