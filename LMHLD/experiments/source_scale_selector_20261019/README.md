# 来源数据训练的尺度选择器验证

2026-10-19，已完成12组基础模型重放及36个轻量选择器头，分别为14,400次和21,600次参数更新。**平均有小幅净收益，但预定稳定性及绝对误检门槛未通过，保留离线候选，不替换默认模型。** 训练进程已退出。沿用上一轮原始图块、六地区轮流留出和两个种子；基础模型只重放上一轮单尺度固定训练分支，每次1,200步。

## 结果

所有方法在本轮相同来源校准半集上独立校准阈值。下表先按六地区宏平均，再平均两个种子；不能与上一轮使用全部来源验证图块校准的分数直接混比。

| 方法 | 小目标半覆盖命中率 | 小目标IoU≥0.5匹配率 | 像素F1 | 标注背景误检率 |
| --- | ---: | ---: | ---: | ---: |
| 单尺度五视图集成 | 53.99% | 30.32% | 57.46% | 3.67% |
| 固定平均多尺度 | 52.38% | 34.48% | 56.92% | 3.19% |
| 来源学习常数比例 | 52.94% | 33.50% | 57.26% | 3.32% |
| **输入自适应选择器** | **54.83%** | **35.33%** | **57.72%** | **3.35%** |
| 去掉显式分辨率元信息 | 54.83% | 35.63% | 57.61% | 3.32% |

相对同轮单尺度集成，完整选择器半覆盖命中率平均+0.85个百分点，小目标IoU匹配率+5.01个百分点，像素F1+0.25个百分点，标注背景误检率-0.32个百分点。相对学习常数比例，半覆盖命中率+1.89个百分点，但背景误检率略高约0.03个百分点，不能称所有指标全面超过全部基线。

没有通过稳定性门槛的原因：半覆盖增益在两个种子中分别为+1.64和+0.05个百分点，只有3/6地区在两个种子中均提高；目标地区平均背景误检仍为3.35%，最差地区/种子为7.57%，未达到冻结的3%宏平均和5%单地区门槛。显式分辨率输入没有带来额外半覆盖命中；本轮不支持把元信息输入本身作为已验证的算法创新。

探索性配对原图块重采样（1,000次，固定已拟合模型和校准阈值）中，半覆盖增益95%百分位区间约[-1.09,+2.56]个百分点，像素F1约[-0.06,+0.54]。这是条件于本轮模型的样本不确定性检查，不是独立地区或事件总体置信区间，且原始图块邻近相关性无法核实。不能据此声称稳定泛化突破。

`verification.json`复核12份固定0.5阈值基线精确重放、60份来源学习/校准隔离记录、60组来源阈值与逐图统计、12份头部采样配对及全部冻结指纹，均通过。`comparison.png`展示逐地区主对照。完整数字和各门槛结果见`results.json`，小型门控系数保存在各组`result.json`中，包含对应基础模型状态哈希，不能直接混用现役模型。

本轮说明输入相关的门控比只学一个全局比例有一定价值，下一步需先定位未检出对象在两尺度输入中的信息与响应，再决定是否增加模型复杂度；不在这批目标成绩上继续挑比例、阈值或检查点。

## 冻结设置与复现

- 每个来源地区原验证图块按固定种子拆半：一半学习选择器，另一半校准阈值；目标地区不进入任何拟合或校准。
- 19参数的逐像素选择器依据实际BGRN影像、两尺度概率及名义分辨率，学习整图与局部概率之间的融合权重。
- 对照包括相同五次推理的单尺度集成、固定平均融合、来源标签学习的常数比例，以及不输入分辨率信息的选择器。
- 三种学习头使用同样来源像素、采样顺序、600步优化和正则。候选需同时优于单尺度集成与学习常数比例，不能只超过较弱基线。
- 正式协议、代码哈希和门槛见`protocol.json`；原始图块与内容哈希见`data_manifest.json`。门控系数与完整逐图指标随每组结果保存，不保存大基础模型或概率缓存。
- 这些都是历史开发数据的新受控对照，不是新增独立盲测。采用名义分辨率与标签连通对象，不能代表完整事故边界、跨矿能力或现场误报率。新门控为已有混合/门控思想的应用验证，不宣称方法首创。
