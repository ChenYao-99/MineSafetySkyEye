- 专门以三通道BGR训练恢复了识别能力：普通训练TTA5 F1为60.32%，对照39.63%，提高20.69个百分点；覆盖检出从12.63%到49.13%，背景FPR也从1.93%升到2.86%。缺失真实NIR的既有权重不能替代RGB训练。
- 尺度扰动＋面积筛选相对普通RGB TTA5：严格IoU匹配提高约3.67个百分点，F1降低约2.09个百分点，覆盖检出降低约1.20个百分点，背景FPR降低约0.40个百分点。原主比较未通过，不能称全面优于普通RGB。
- 面积筛选相对各自未筛选多尺度能减少纯背景碎片且基本保留其覆盖，但尚未同时满足全部跨地区绝对FPR和原主比较要求。普通训练两种子、尺度训练种子42均存在某地区FPR>5%。

## 训练与数据边界

- 原四波段匹配协议的六区域全量可用池17275父图，不限于原来512/区域。每组五来源，batch20且来源各4，最多4800步，实际覆盖率与来源入选检查点保存在每组training.json。
- 真正三输入Unet++/ResNet34，无NIR或第四通道代理。两个训练臂共享初始化、父图、视图抽签、旋转/翻转及总预算；只有是否使用随机象限视图不同。共享初始化来自可重现四输入随机初始化，第一卷积只保留前三通道，不使用已训练模型初始化。
- 对4936张原官方val图像重新做BGR哈希审计，训练/验证精确重叠0；两个训练臂的可用池一致。无地理邻接元数据，不能证明空间独立。
- 来源选择半集选检查点，另一半校准像素阈值与面积规则，目标不进入梯度、选模或校准。对象定义继承此前：名义面积≤2500m²、8连通且排除父图边界。
- 六组来源政策在各组目标推理前保存；primary_comparison_protocol.json在第一张目标预测前补齐跨训练臂对照和门槛。全部原始目标结果、模型、门槛均未按结果更改。
