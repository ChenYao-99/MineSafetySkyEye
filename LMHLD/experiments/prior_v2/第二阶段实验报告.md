## 一、实验目的

在实验一（推理时先验软约束，验证先验信息有效性）基础上，将地质先验**融入训练过程**：
损失函数按空间位置加权 `loss = BCE×loss × (1 + λ·prior)`，让模型在学习阶段即关注高地质风险区域，
实现从"推理修正"到"学习先验"的质变，对齐申报书创新点一的完整技术路线。

## 二、实验协议（保证可比性）

| 维度 | 设置 |
|---|---|
| 模型 | UnetPlusPlus / resnet34 / 无预训练 / 4通道[B,G,R,NIR] / patch=32（与 train.py 完全一致） |
| 优化 | SGD lr=0.01, momentum=0.9, ExponentialLR(0.99)（与 train.py 完全一致） |
| 增强 | HorizontalFlip+VerticalFlip+RandomRotate90（与 train.py 完全一致） |
| 随机种子 | **固定 seed=42**（对照组与实验组同种子，消除随机性干扰） |
| 先验图 | 与实验一相同：prior = 0.5·bare(NDVI反推) + 0.5·rough(NIR局部标准差)，增强后计算 |
| 变量 | 仅 λ（先验权重）：0 / 0.5 / 1.0 / 2.0 |
| 评估 | 测试集：像素级 F1/BLDS + GT 连通域分尺度区域召回（小≤25px/中26-100/大>100px） |

## 四、核心结论

1. **训练阶段融入先验有效且跨区域一致**：两区域所有 λ>0 的整体 F1 均优于同协议基线
   （Emilia +1.2~2.3pp，Gorkha +1.0pp），BLDS 同步提升——先验信息在训练中确实提供了可学习的风险分布信号。
2. **λ 提供精度-召回调节旋钮**：
   - λ=0.5：整体精度最优（Emilia F1 0.7642，+2.3pp），适合追求高置信度场景
   - λ=1.0：整体与小尺度兼顾（Emilia 双升：F1 +1.2pp、小区召回 +4.3pp），为推荐默认配置
   - λ=2.0：强先验，性能回落，说明先验权重存在最优区间（过强会引入噪声）
3. **与实验一的关系**：实验一证明先验与风险分布相关性真实存在（推理加权有效）；实验二证明
   该相关性可被模型在训练中学习（损失加权有效）。两者互补，且**可叠加**（训练加权 + 推理加权），
   为后续 SAPSS 补丁选择优化提供完整证据链。
