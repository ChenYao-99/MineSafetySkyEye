## 实际结论

- 候选级全局支持保护有实用价值。来源面积筛选将纯背景连通域从46.45降至35.99个/Mpx（减少22.52%），覆盖检出从54.66%到54.44%，严格IoU从32.41%到32.18%。
- 复杂分类器未优于简单规则，原预注册的学习筛选主假设未通过；没有修改其门槛或把对照改写成主方法成功。
- 面积规则是预先列出的对照，从本开发结果中选为新候选后冻结，再做[新增682图块验收](../component_acceptance_20261020/README.md)。该独立阶段的同事件新增样本验收通过，范围不能扩大为新地区或现场验收。

## 机制与对照

1. 骨干、一次全局+四象限输入、50:50概率均值、来源2%像素阈值均复用上一轮。提取8连通预测对象，不改CNN权重。
2. 全局单视图的保护阈值仅用五来源校准半集确定，使平均背景FPR≤2%。对象中任一像素达到此全局阈值，即获得全局支持；受保护对象始终保留。这样局部分支仍能扩展对象覆盖，缺乏全局支持的孤立候选再受筛选。
3. 单像素对象保持不变，延续上一轮纯背景连通域只统计面积≥2像素的口径。所有方法只删除完整预测对象，不分割、填洞或合并对象。
4. 面积方法使用`log1p(像素面积×名义GSD²)`，置信度方法使用对象平均概率相对原像素阈值的归一化裕量。两者的对象级阈值都只在来源校准集选择。
5. 学习方法以16个概率/形状特征拟合L2逻辑回归；任何GT像素重叠为正，零重叠为负。训练按来源地区/类别均衡，标准化只来自来源拟合半集。推理不接收GT、地区编号、坐标、日期或原始光谱外观。
6. 来源对象阈值在101个来源分位点及保留全部/删除未保护对象端点上搜索。在来源覆盖检出均值最多损失0.5个百分点、各地区最多2个百分点、F1均值最多损失0.5个百分点的约束下，减少平均纯背景连通域；精确IoU也检查均值0.5/地区2个百分点损失上限，必要时回退。平分时选择更保守阈值。
7. 不含全局保护的消融使用同一个分类器、自己的来源校准阈值，展示保护机制影响。原多尺度和TTA5分数逐条复现上一轮，排除换骨干或换像素阈值造成的假增益。

## 复核与工程状态

- 来源拟合/校准使用原来的互斥半集，目标政策先保存，再解码本轮目标网格/标签。像素与候选阈值联合复用了来源校准半集，不能据此声称形式化风险保证。
- 重新拟合六个分类器、重放所有来源候选阈值选择；从冻结骨干重算来源全局概率阈值及每个来源对象的保护标记；从原目标概率缓存重建全部七方法的掩膜、决策和分数，均一致。
- 新模块`D:/LMHLD/component_filter.py`提供GT无关的对象特征、评分与整对象掩膜接口。实验入口为`D:/LMHLD/validation/component_screen.py`。尚未接入默认矿区推理链路，需先对齐RGB输入、尺度及现场工作条件。
- 没有新增CNN训练或CNN权重，没有下载、外部API、官方test或矿区保留集预测。每种候选方法仍为五次CNN前向，另加CPU连通域与筛选开销。
- 压缩来源连通域/特征用于复核，目标只保存保留/删除决策，避免复制原始影像与已有目标概率。源代码、政策和复核已被后续验收冻结，后续优化必须另建实验。
- 开发评估为历史已暴露的三个地区、两个种子，不是独立新矿区结果。纯背景连通域/Mpx是基于当前GT与面积≥2像素的代理指标，不等于现场告警数或已测得的人工任务节约。
