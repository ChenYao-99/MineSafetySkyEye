# 矿区实验与工程验证

本目录集中保存数据来源检查、研究协议、对照实验和工程验收脚本。阅读入口见[检测模块 README](../README.md)。需要安装或启动服务时，从[团队统一安装](../../GeoMMAgent/deployment/DEPLOYMENT.md#团队统一安装)开始。

- [源码入口与历史归档](SOURCE_LAYOUT.md)列出常用模块和依赖的本地资产。
- [正样本扩充与 RGB 适配](../experiments/rgb_guarded_20261001/正样本扩充与RGB适配结果.md)记录 2026-10-02 的开发对照。该轮加入的 200 个弱标注正图块来自一个训练矿区。Hpakant 图示参考在组合阶段已经使用，后续作为回归材料。
- [共同观测范围验证](../../GeoMMAgent/maintenance/observation_context_20261106/README.md)记录现有双期输入处理与测试。

比较指标时应同时记录模型、波段、数据角色、阈值和评价范围。白格 ROI 的弱标注正图块曾用于 `finetune_negatives.build_dataset()`，白格响应属于已见场景检查。用于独立评价的矿区事件应保持与训练、模型选择和阈值校准隔离。

复现历史实验时，按对应报告取得所需的影像、冻结协议和权重，并核对原始来源与使用条件。
